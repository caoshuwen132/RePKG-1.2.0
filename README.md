## 1.2.0(2026-07-26)
- 新增“自定义路径”设置，可分别指定 Steam 创意工坊目录和默认提取目录。
- 支持直接选择 SteamLibrary、steamapps、workshop 或 workshop\content\431960 目录，程序会自动识别实际壁纸目录。
- 自定义路径会保存到程序目录下的 path-settings.json；留空可继续使用原有自动检测，亦可一键恢复自动检测。
- 自定义提取目录同时适用于单个壁纸和全部壁纸提取，并继续为每个壁纸创建独立的名称子文件夹。
- 修复点击“保存路径”或“恢复自动检测”时，因路径配置键名不一致导致程序闪退的问题。
- 为设置页增加垂直滚动支持，修复窗口高度不足时底部信息显示不全的问题。
- 在“已安装”页第二行、“提取全部”按钮右侧新增“刷新壁纸”按钮，按钮字号、尺寸和样式与原按钮保持一致。
- 下载或订阅新壁纸后，可点击“刷新壁纸”在后台重新扫描创意工坊并更新预览列表，无需重新启动程序。
- 刷新前会清空旧缩略图和选中状态，避免重复显示或残留旧壁纸信息；刷新期间按钮会暂时禁用，防止重复操作。
- 缩短保存地址栏以容纳新增按钮，第二行总长度保持不变，不影响右侧壁纸详情和操作区域。
- 修复部分动态 TEX 使用非原始 mipmap 时，GIF 转换警告被误报为错误弹窗的问题；保留原始 TEX 文件并继续提取其他内容。
- 将单个 TEX mipmap 的安全读取上限由 250 MB 调整为 512 MB，修复部分大型 4K/60 帧动态纹理无法转换为视频的问题。
- 新增 QuickTime `ftypqt` 视频纹理容器支持，修复部分 TEX 视频因无法识别 MP4 头而转换失败的问题。
- 新增条件式 TEXB0004 双主题纹理兼容：自动识别并分别导出各主题的完整分辨率 PNG，修复旧解析器将其误判为 mipmap 长度越界的问题；不导出无用的低分辨率 mipmap 层级。
- 条件式双主题 TEX 的兼容转换改为静默完成，修复转换成功提示被 GUI 误判为错误弹窗的问题。
- 修复启用“仅保留图片”后，壁纸名称子文件夹中的 `.tex` 和 `.tex-json` 未被清理的问题；关闭该选项时仍会完整保留原始纹理和元数据。
- 优化 RePKG 包装程序的标准输出与错误输出读取方式，避免大量日志同时产生时管道互相等待导致提取卡住，并将包装组件版本统一为 1.2.0.0。
- 修复取消勾选“使用壁纸名作为子目录名称”后不再创建子文件夹的问题；现在单个和全部提取都会创建独立子文件夹，勾选时使用壁纸名称，取消时使用壁纸 ID。
- 新增 GIF 预览动画支持，壁纸列表缩略图和右侧详情预览均可按照 GIF 原始帧间隔播放；切换壁纸时会停止旧动画，页面卸载时自动暂停。
- 修复带透明增量帧的 GIF 在播放一段时间后出现残缺、发白的问题；播放前会按 GIF 帧叠加规则生成完整画面，并限制超大预览图的解码尺寸以控制内存占用。
- 功能设计参考 [NaiHeeeee/repkg-gui](https://github.com/NaiHeeeee/repkg-gui) 的自定义路径功能，并针对当前 WPF 版本重新实现。

## 1.1.0(2026-07-24)
- 将 RePKG 核心升级到 v0.4.0-alpha，新增 TEXB0004 纹理格式支持，修复部分新壁纸提取时报错的问题。
- 单个壁纸提取时，自动创建以壁纸名称命名的子文件夹。
- 全部壁纸提取时，为每个壁纸分别创建以壁纸名称命名的子文件夹，避免不同壁纸的文件混在一起。
- 自动处理壁纸名称中的 Windows 非法文件名字符和重名情况。
- 修复全部提取成功后，壁纸名称进度信息被误报为错误弹窗的问题。
